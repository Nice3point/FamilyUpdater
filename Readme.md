# FamilyUpdater

**FamilyUpdater** is a Revit plugin designed to streamline the process of updating Revit model files to the current version of Revit. 
Whether you're dealing with project files, family files, templates, or family templates, this tool ensures that your files are compatible with the latest Revit release, saving you time and effort in manual upgrades.

## Features

- **Automatic File Conversion**: Automatically updates Revit files to the version in which the plugin is run.
- **Batch Processing**: Supports updating multiple files at once, ensuring consistency across your project.
- **File Format Compatibility**: Works seamlessly with the following Revit file formats
    - .rvt (Revit Project Files)
    - .rfa (Revit Family Files)
    - .rte (Revit Template Files)
    - .rft (Revit Family Template Files)

## Installation

To install the FamilyUpdater plugin:

- Navigate to the [**Releases**](https://github.com/Nice3point/FamilyUpdater/releases/latest) section of this repository.
- Download the latest MSI installer file.
- Run the installer and follow the on-screen instructions to complete the installation.

## Usage

Once installed, using the FamilyUpdater is simple:

- Open Revit.
- Go to the **Add-Ins** tab on the Revit ribbon.
- Click the **External Tools** button to view the list of available tools.
- Select **Family Updater** from the list.
- The plugin will automatically upgrade the loaded file to the current version of Revit.

Requirements

- Revit Version: The plugin is compatible with Revit 2020 and later.
